# Microsoft Store product features (de-de)

Paste into Partner Center → Store listings → **German (Germany)** → **Product features**.

Short summaries of the product's key features. The Store shows them as a bulleted list. Up to 20 app features. Each feature is at most 200 characters. Paste the sentence only; Partner Center adds the bullet.

- Lesen und senden mit IMAP, POP3 und SMTP. Mehrere Postfächer bleiben offen. Profile füllen die Hosts für Gmail, Microsoft 365 und italienische PEC-Anbieter.
- Öffnet einen PEC- oder REM-Umschlag und zeigt die innere Nachricht. Die Spalte Typ markiert PEC, einen Nachweis, REM oder eine digitale Signatur.
- Die Spalte Zustellung folgt dem Nachweis des Betreibers: angenommen, abgelegt, abgeholt oder fehlgeschlagen. Italienische PEC hat keine Lesebestätigung.
- Nach zertifiziertem Senden wird Gesendet den Nachweisen über Message-Id, daticert.xml und das Betreffpräfix zugeordnet.
- Zeigt eine FatturaPA als lesbare Seite. Exportiert gewählte Nachrichten als ursprüngliche .eml-Dateien.
- Von ist das verbundene Postfach. Senden nutzt diese SMTP-Identität. Eine freie Absenderadresse wird nicht eingetippt.
- Aktenmarken bleiben auf diesem PC. Die Suche umfasst Betreff, Text, Anlagentext und diese Marken.
- Nachrichten abrufen speichert den ganzen IMAP-Ordner auf diesem PC, als mail.db plus die ursprünglichen .eml-Dateien.
- Die Bedeutungssuche nutzt ein Modell auf dem Gerät. Vektoren bleiben in mail.db. Post geht nicht in die Cloud.
- Regeln verschieben, löschen, kennzeichnen und markieren, auch in einen Ordner eines anderen Kontos. Import von JSON oder einer älteren Regeldatei.
- Ein Ordnerspeicher ist ein Verzeichnis von .eml-Dateien mit eigenem Index. Importieren Sie eine Outlook-PST in einen Speicher.
- Länderpakete schalten Nachweistexte für Italien, Europa, Frankreich, Deutschland, Spanien und die Schweiz ein oder aus.
- Die Aufbewahrung verschiebt alte Post eines Ordners in den Papierkorb. Der Papierkorb kann bleiben oder nach Tagen geleert werden.
- Als Spam markieren merkt sich diese Nachricht auf diesem PC und wendet den Hinweis auf jedes Postfach an. Kein Spam löscht ihn.
- Die Hintergrundsynchro kann beim Start laufen und jedes gespeicherte Postfach abgleichen, ohne dass jemand bei Windows angemeldet ist.
- Easy Migration schreibt ein mit Passphrase gesperrtes Paket aus Post, Konten und Geheimnissen und stellt es auf einem anderen PC wieder her.
- Gmail und Microsoft 365 melden sich über Identity Hub an. Kennwörter und Token bleiben außerhalb von settings.json.
- Die Oberfläche ist Englisch, Italienisch, Französisch, Deutsch oder Spanisch. Hilfe öffnet das Protokoll und sucht ein Update.

The listing description and the other Store text fields are in [description.md](description.md).
